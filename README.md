# Ring Auto-Reconnect Chrome Extension

Automatically reconnects Amazon Ring camera live view when it disconnects.

## Installation

1. Extract this ZIP file to a folder
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" (toggle in top right)
4. Click "Load unpacked"
5. Select the extracted folder
6. Visit ring.com and the extension will work automatically!

## Features

- 🔄 Automatically detects when Ring live view disconnects
- 🖱️ Clicks the reconnect button for you
- ⚡ Works in the background
- 🎯 Smart detection of various reconnect button styles
- 🛡️ Built-in debouncing to prevent excessive clicking

## How It Works

The extension monitors the Ring website for disconnection messages and automatically clicks the reconnect button when found.

## Troubleshooting

**Extension not working?**
- Make sure you're on ring.com
- Check that the extension is enabled in chrome://extensions/
- Try refreshing the Ring page

## Privacy

- Only runs on ring.com domains
- No data collected or transmitted
- All processing happens locally in your browser
